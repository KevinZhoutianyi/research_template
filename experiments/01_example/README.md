# First research question

Replace this example folder with the first experiment needed by the argument.
Number subsequent experiments in the order their questions arise, not by run date.

Record the question, competing predictions, fixed inputs, measurement, commands,
and evidence paths. Mark the outcome pending until outputs pass validation.
Add `run.py` only when there is a real implementation. Import reusable code from
the installed shared package; do not copy it into each experiment.
