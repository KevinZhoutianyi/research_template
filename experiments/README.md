## Convention
- Create new numbered folders (`01_xxx/`, `02_xxx/`, ...) for new experiments — don't edit old ones.
- `../src/` holds the shared package and shared configs, data, tests, and launchers.
- Start with a question and protocol in `README.md`. Add runners, figures, and small results when needed; do not create empty placeholders.
- This README should only contain brief descriptions of each experiment. Detailed setup, results, and observations belong in each experiment's own `README.md`.
- Large outputs go in the ignored bulk subdirectories of `../src/data/`.
